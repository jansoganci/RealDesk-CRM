SECTION 2: EDITABLE CLAUSE SOLUTIONS (OPTIONS + COMPARISON)
APPROACH 1: Simple JSON Field with In-Form Editing
Architecture:
	•	Store edited clauses as JSON in contract_details.custom_clauses (new JSONB column)
	•	Display clauses as editable textarea fields below the contract form
	•	On PDF generation, use custom clauses if present, else use defaults
Database Changes:
ALTER TABLE contract_details 
ADD COLUMN custom_clauses JSONB DEFAULT NULL;

-- Structure: { "genel": ["clause1", "clause2", ...], "ozel": [...] }

Frontend Changes:
	•	Add new form section: EditableClausesSection.tsx
	•	Prefill with GENEL_SARTLAR and OZEL_SARTLAR on mount
	•	Store edited clauses in form state (React Hook Form)
	•	Validate: each clause must have content (Zod schema)
PDF Service Changes:
// Instead of importing hardcoded arrays:
const genelSartlar = data.customClauses?.genel || GENEL_SARTLAR;
const ozelSartlar = data.customClauses?.ozel || OZEL_SARTLAR;

Pros:
	•	✅ Simplest implementation (1-2 days)
	•	✅ No additional tables (single JSONB column)
	•	✅ Minimal PDF changes (fallback to defaults)
	•	✅ Backward compatible (NULL = use defaults)
	•	✅ Fast to query (single table)
Cons:
	•	❌ No clause versioning (can't track changes over time)
	•	❌ No clause reuse (each contract stores full copy)
	•	❌ Large JSON payloads (32 clauses × ~200 chars = 6KB per contract)
	•	❌ No admin clause management (defaults still hardcoded)
	•	❌ Difficult to update defaults (must migrate existing contracts)
	•	❌ No audit trail (who edited what clause when)
Best For: Quick MVP, low contract volume (<1000 contracts)

APPROACH 2: Template System with Override Pattern
Architecture:
	•	Create contract_clause_templates table for default clauses
	•	Store per-contract overrides in contract_clause_overrides table
	•	Display clauses as cards with "Use Default" / "Customize" toggle
	•	On PDF generation, merge overrides with template
Database Schema:
-- Default clause templates (shared across all contracts)
CREATE TABLE contract_clause_templates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  category TEXT NOT NULL, -- 'genel', 'ozel', 'tahliye'
  sequence_order INT NOT NULL,
  title TEXT, -- optional clause title
  content TEXT NOT NULL,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);

-- Per-contract clause overrides (only when edited)
CREATE TABLE contract_clause_overrides (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  contract_id UUID REFERENCES contracts(id) ON DELETE CASCADE,
  template_clause_id UUID REFERENCES contract_clause_templates(id),
  custom_content TEXT NOT NULL, -- overridden text
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now(),
  UNIQUE(contract_id, template_clause_id)
);

CREATE INDEX idx_overrides_contract ON contract_clause_overrides(contract_id);

Data Migration:
	•	Seed contract_clause_templates with current GENEL_SARTLAR + OZEL_SARTLAR
	•	Keep hardcoded arrays as fallback for now
Frontend Implementation:
	•	Fetch templates on contract create page load
	•	Display each clause in an accordion/card
	•	Show "Default" badge + edit icon
	•	On edit: create override record (save to state until submit)
	•	Form submission: save overrides to database
PDF Service Changes:

// Render in PDF

  renderClause(clause.content, idx);

Pros:
	•	✅ Efficient storage (only store changes, not full copy)
	•	✅ Template versioning (can update defaults centrally)
	•	✅ Admin UI potential (manage templates separately)
	•	✅ Audit trail (created_at, updated_at on overrides)
	•	✅ Clause reuse (templates shared across contracts)
	•	✅ Scalable (good for 10,000+ contracts)
Cons:
	•	⚠️ More complex (2 tables, joins required)
	•	⚠️ Query overhead (must join templates + overrides for PDF)
	•	⚠️ Migration required (seed templates table)
	•	⚠️ Admin UI needed (to manage templates - future work)
	•	⚠️ Versioning complexity (updating templates affects existing contracts)
Best For: Production SaaS, long-term scalability, multi-user teams

SECTION 3: FINAL RECOMMENDED SOLUTION
RECOMMENDATION: Approach 2 (Template System with Override Pattern)
Rationale: Best balance of simplicity, scalability, and 2025 SaaS best practices.
Why This Approach?
1. Aligns with Industry Standards
	•	Modern SaaS platforms (PandaDoc, Juro, DocuSign) use template-based systems
	•	Follows "Don't Repeat Yourself" (DRY) principle
	•	Enables future admin features without rewrite
2. Fits Your Tech Stack Perfectly
	•	PostgreSQL excels at relational data (templates + overrides)
	•	Supabase RLS works seamlessly with foreign keys
	•	React Hook Form handles nested data well
	•	TypeScript types easily generated from schema
3. Solves Current Pain + Future Needs
	•	✅ Current: Agents can edit clauses per contract
	•	✅ Future: Admin can update default templates
	•	✅ Future: Audit trail for compliance
	•	✅ Future: Clause analytics (most edited clauses)
4. Minimal Risk
	•	Incremental migration (seed templates, keep hardcoded fallback)
	•	Backward compatible (NULL overrides = use template)
	•	Can rollback to hardcoded if needed
5. Performance Optimized
	•	Single join for PDF generation (templates LEFT JOIN overrides)
	•	Index on contract_id for fast override lookups
	•	JSONB aggregation for efficient clause merging

Phase 3: Service Layer (Day 2)
3.1 Clauses Service (/src/services/clauses.service.ts)
import { supabase } from '@/config/supabase';
import { getAuthenticatedUserId } from '@/lib/auth';
import type { ContractClauseTemplate, MergedClause, ClausesForPdf } from '@/types/contract.types';

class ClausesService {
  /**
   * Fetch all templates for current user
   */
  async getTemplates(): Promise<ContractClauseTemplate[]> {
    const userId = await getAuthenticatedUserId();
    
    const { data, error } = await supabase
      .from('contract_clause_templates')
      .select('*')
      .eq('user_id', userId)
      .eq('is_active', true)
      .order('category')
      .order('sequence_order');
    
    if (error) throw error;
    
    // If no templates, seed them
    if (!data || data.length === 0) {
      await this.seedTemplatesForCurrentUser();
      return this.getTemplates(); // recursive call
    }
    
    return data;
  }
  
  /**
   * Get merged clauses for contract (templates + overrides)
   */
  async getMergedClauses(contractId: string): Promise<ClausesForPdf> {
    const userId = await getAuthenticatedUserId();
    
    // Fetch templates with LEFT JOIN overrides
    const { data, error } = await supabase
      .from('contract_clause_templates')
      .select(`
        id,
        category,
        sequence_order,
        content,
        contract_clause_overrides!left (
          custom_content
        )
      `)
      .eq('user_id', userId)
      .eq('is_active', true)
      .eq('contract_clause_overrides.contract_id', contractId)
      .order('sequence_order');
    
    if (error) throw error;
    
    // Map to merged format
    const merged: MergedClause[] = data.map((row: any) => ({
      template_id: row.id,
      category: row.category,
      sequence_order: row.sequence_order,
      content: row.contract_clause_overrides?.[0]?.custom_content || row.content,
      is_customized: !!row.contract_clause_overrides?.[0]
    }));
    
    // Group by category
    return {
      genel: merged.filter(c => c.category === 'genel'),
      ozel: merged.filter(c => c.category === 'ozel'),
      tahliye: merged.find(c => c.category === 'tahliye')?.content || ''
    };
  }
  
  /**
   * Save clause overrides for contract
   */
  async saveOverrides(
    contractId: string,
    overrides: { templateId: string; content: string }[]
  ): Promise<void> {
    const userId = await getAuthenticatedUserId();
    
    // Delete existing overrides for this contract
    await supabase
      .from('contract_clause_overrides')
      .delete()
      .eq('contract_id', contractId);
    
    // Insert new overrides
    if (overrides.length > 0) {
      const { error } = await supabase
        .from('contract_clause_overrides')
        .insert(
          overrides.map(o => ({
            contract_id: contractId,
            template_clause_id: o.templateId,
            custom_content: o.content,
            user_id: userId
          }))
        );
      
      if (error) throw error;
    }
  }
  
  /**
   * Seed templates for current user (from hardcoded defaults)
   */
  private async seedTemplatesForCurrentUser(): Promise<void> {
    const { data, error } = await supabase.rpc('seed_default_contract_clauses', {
      p_user_id: await getAuthenticatedUserId()
    });
    
    if (error) throw error;
  }
}

export const clausesService = new ClausesService();

  const [templates, setTemplates] = useState<ContractClauseTemplate[]>([]);
  const [editedClauses, setEditedClauses] = useState<Map<string, string>>(new Map());
  const [loading, setLoading] = useState(true);
  
  useEffect(() => {
    loadTemplates();
  }, []);
  
  const loadTemplates = async () => {
    try {
      const data = await clausesService.getTemplates();
      setTemplates(data);
      
      // Initialize form value
      form.setValue('clauseOverrides', []);
    } catch (error) {
      console.error('Failed to load clause templates:', error);
    } finally {
      setLoading(false);
    }
  };
  
  const handleEdit = (templateId: string, content: string) => {
    const newEdited = new Map(editedClauses);
    newEdited.set(templateId, content);
    setEditedClauses(newEdited);
    
    // Update form state
    const overrides = Array.from(newEdited.entries()).map(([templateId, content]) => ({
      templateId,
      content
    }));
    form.setValue('clauseOverrides', overrides);
  };
  
  const handleReset = (templateId: string) => {
    const newEdited = new Map(editedClauses);
    newEdited.delete(templateId);
    setEditedClauses(newEdited);
    
    // Update form state
    const overrides = Array.from(newEdited.entries()).map(([templateId, content]) => ({
      templateId,
      content
    }));
    form.setValue('clauseOverrides', overrides);
  };
  
  const isEdited = (templateId: string) => editedClauses.has(templateId);
  
  const genelClauses = templates.filter(t => t.category === 'genel');
  const ozelClauses = templates.filter(t => t.category === 'ozel');
  
  return (
    <Card>
      <CardHeader>
        <CardTitle>Sözleşme Maddeleri</CardTitle>
        <CardDescription>
          Varsayılan sözleşme maddelerini bu sözleşme için özelleştirebilirsiniz.
          Değişiklik yapmak istediğiniz maddeleri düzenleyin.
        </CardDescription>
      </CardHeader>
      <CardContent className="space-y-6">
        {/* General Conditions */}
        <div>
          <h3 className="text-sm font-semibold mb-3">Genel Şartlar ({genelClauses.length} madde)</h3>
          <Accordion type="multiple" className="space-y-2">
            {genelClauses.map((template, idx) => (
              <AccordionItem key={template.id} value={template.id}>
                <AccordionTrigger className="text-sm hover:no-underline">
                  <div className="flex items-center gap-2">
                    <span>{idx + 1}. Madde</span>
                    {isEdited(template.id) && (
                      <Badge variant="secondary" className="text-xs">Özelleştirildi</Badge>
                    )}
                  </div>
                </AccordionTrigger>
                <AccordionContent>
                  <ClauseEditor
                    template={template}
                    isEdited={isEdited(template.id)}
                    editedContent={editedClauses.get(template.id)}
                    onEdit={(content) => handleEdit(template.id, content)}
                    onReset={() => handleReset(template.id)}
                  />
                </AccordionContent>
              </AccordionItem>
            ))}
          </Accordion>
        </div>
        
        {/* Special Conditions */}
        <div>
          <h3 className="text-sm font-semibold mb-3">Özel Şartlar ({ozelClauses.length} madde)</h3>
          <Accordion type="multiple" className="space-y-2">
            {ozelClauses.map((template, idx) => (
              <AccordionItem key={template.id} value={template.id}>
                <AccordionTrigger className="text-sm hover:no-underline">
                  <div className="flex items-center gap-2">
                    <span>{idx + 1}. Madde</span>
                    {isEdited(template.id) && (
                      <Badge variant="secondary" className="text-xs">Özelleştirildi</Badge>
                    )}
                  </div>
                </AccordionTrigger>
                <AccordionContent>
                  <ClauseEditor
                    template={template}
                    isEdited={isEdited(template.id)}
                    editedContent={editedClauses.get(template.id)}
                    onEdit={(content) => handleEdit(template.id, content)}
                    onReset={() => handleReset(template.id)}
                  />
                </AccordionContent>
              </AccordionItem>
            ))}
          </Accordion>
        </div>
      </CardContent>
    </Card>
  );
}

// Subcomponent for editing individual clause
function ClauseEditor({
  template,
  isEdited,
  editedContent,
  onEdit,
  onReset
}: {
  template: ContractClauseTemplate;
  isEdited: boolean;
  editedContent?: string;
  onEdit: (content: string) => void;
  onReset: () => void;
}) {
  const [isEditing, setIsEditing] = useState(false);
  const [localContent, setLocalContent] = useState(editedContent || template.content);
  
  const handleSave = () => {
    onEdit(localContent);
    setIsEditing(false);
  };
  
  const handleCancel = () => {
    setLocalContent(editedContent || template.content);
    setIsEditing(false);
  };
  
  const handleResetToDefault = () => {
    setLocalContent(template.content);
    onReset();
    setIsEditing(false);
  };
  
  return (
    <div className="space-y-3">
      {isEditing ? (
        <>
          <Textarea
            value={localContent}
            onChange={(e) => setLocalContent(e.target.value)}
            rows={6}
            className="font-mono text-sm"
          />
          <div className="flex gap-2 justify-end">
            <Button
              type="button"
              variant="outline"
              size="sm"
              onClick={handleCancel}
            >
              İptal
            </Button>
            <Button
              type="button"
              size="sm"
              onClick={handleSave}
            >
              Kaydet
            </Button>
          </div>
        </>
      ) : (
        <>
          <p className="text-sm text-muted-foreground leading-relaxed">
            {editedContent || template.content}
          </p>
          <div className="flex gap-2">
            <Button
              type="button"
              variant="outline"
              size="sm"
              onClick={() => setIsEditing(true)}
            >
              <Pencil className="h-4 w-4 mr-2" />
              Düzenle
            </Button>
            {isEdited && (
              <Button
                type="button"
                variant="ghost"
                size="sm"
                onClick={handleResetToDefault}
              >
                <RotateCcw className="h-4 w-4 mr-2" />
                Varsayılana Dön
              </Button>
            )}
          </div>
        </>
      )}
    </div>
  );
}

// Update render functions to accept merged clauses
function renderPage2_GenelSartlar(doc: jsPDF, clauses: MergedClause[]): void {
  const { margins, fontSize } = PDF_CONFIG;
  let y = margins.top;
  
  doc.setFontSize(fontSize.subtitle);
  setFontBold(doc);
  doc.text('GENEL ŞARTLAR', doc.internal.pageSize.width / 2, y, { align: 'center' });
  y += 12;
  
  doc.setFontSize(fontSize.small);
  setFontNormal(doc);
  
  const pageWidth = doc.internal.pageSize.width - margins.left - margins.right;
  
  clauses.forEach((clause, index) => {
    const maddeText = `${index + 1}. ${clause.content}`;
    const lines = doc.splitTextToSize(maddeText, pageWidth);
    
    if (y + (lines.length * 4) > doc.internal.pageSize.height - margins.bottom) {
      doc.addPage();
      y = margins.top;
    }
    
    doc.text(lines, margins.left, y);
    y += lines.length * 4 + 3;
  });
}
