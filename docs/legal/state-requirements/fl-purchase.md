# Florida — Residential Purchase (research summary)

**Status:** Phase 1 research only · Not attorney-reviewed · Not a Florida Realtors contract  
**Sources consulted:** Fla. Stat. §404.056(5) radon; Johnson v. Davis material-fact disclosure duty; §§720.401 (HOA), 718.503 (condo), 161.57 (coastal); secondary notes on flood disclosure reforms (2024+).

## 1. Mandatory disclosures

| Topic | Understanding | Uncertainty |
|-------|---------------|-------------|
| Material latent defects | Case-law duty (Johnson v. Davis) to disclose known non-obvious material facts | No single statewide “TDS form” statute like CA |
| Radon | Same statutory notice language as leases (§404.056(5)) | Must appear on a document executed at/before contract |
| Flood | Newer mandatory flood disclosure framework (secondary sources cite Oct 2024+) | Exact current form/fields — **UNCERTAIN**; flag gap |
| HOA | §720.401 disclosure summary when mandatory membership | Wizard gap |
| Condo | §718.503 document package + rescission rights | Wizard gap |
| Coastal CCCL | §161.57 coastal construction control line disclosure when applicable | Wizard gap |
| Lead paint | Federal | Modeled |
